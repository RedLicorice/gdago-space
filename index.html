Giuseppe D'Agostino Rome, IT — full remote drawn 2026

Curious builder, pragmatic by choice. Every project here is still a small experiment — staying close to the part I actually love: building things, and understanding how they work.

Built from scratch

Three systems built because the off-the-shelf version was too slow, too rigid, or didn't exist. Not demos — still running.

logHUB

go sse svelte mcp endpoint

Unifies server logs with the diagnostics a client agent collects on users' machines, in one timeline. Ships an MCP endpoint so a coding agent can read both live while it iterates — the thing that makes AI-assisted debugging verifiable instead of vibes.

running, not public

GoGitIt

go svelte websocket tailscale

The repo lived on a network share and Git over it was slow, so the computation moved to where the data already was. One working copy, many stations, near-local git status from anywhere.

running, not public

Nexus Patch System

python fastapi c#/.net

OAuth2 with proactive refresh behind a swappable interface, OpenAPI REST surface, a C# desktop client. In production it ships a 2 GB+ client update in about two and a half minutes.

running, not public

+ What's underneath

All three run on apps-platform: who the player is, where their save lives, how the browser hears about it. One account, every game — sign up once and it works in Il Porciotto, Crown Rush, whatever's next. It also runs anywhere — my laptop, a cloud cluster, a home server under the desk, in principle a toaster with enough RAM — without rewriting auth or storage each time. Postgres, Firestore, Redis, Google Pub/Sub, or just memory, picked by environment variable, not by rewrite.
